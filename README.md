# SOC Consulting landing page

Static corporate landing page built with Next.js, React, TypeScript and Tailwind CSS.

## Brand

The identity uses a focused, editorial consulting style rather than a software-product aesthetic. The segmented circular mark represents alignment, focus and movement around a clear center.

- Ink: `#20182F`
- Paper: `#F6F0E5`
- Coral: `#EB684F`
- Sage: `#A9BF68`
- Lilac: `#A9A6E8`

Logo assets:

- `public/soc-mark.svg` — standalone mark
- `public/soc-consulting-logo.svg` — horizontal lockup
- `public/favicon.svg` — browser icon

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Validation

```bash
npm run typecheck
npm run build
npm audit
```
